# Being a cognate licenses skipping the meaning drill, and nothing else

An item whose meaning is obvious from the language the learner reads skips the drill that
teaches its meaning. It skips nothing else.

It previously skipped three rungs at once, which also skipped the de/het drill and both
dictation drills. Resembling a word you already know tells you the meaning; it tells you
nothing about the item's article, and nothing about how it sounds. Switching glosses from
French to English nearly doubles the number of items flagged — from 29 to 57, newly
including *het water*, *de man*, *de school*, *goed* and *hallo* — so the over-claim would
have skipped the sound drills on precisely the basic words whose sound is the hard part.

## Consequences

Because the claim is now this narrow, the set of cognates may follow the display language
freely. An earlier intention to pin it to French was withdrawn: it was a patch for a jump
that claimed too much, and the jump no longer does.
