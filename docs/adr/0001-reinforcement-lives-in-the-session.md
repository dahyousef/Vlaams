# Sub-day reinforcement lives in the session, not in the schedule

Every stored interval is at least one day. The reinforcement of being asked a word again a
few minutes after meeting it still happens, but the running session does it, rather than
the item being scheduled to return.

Stored as a due date, a twelve-minute return competed for the session's places like any
other review. With about twenty items sitting at the first rung, those returns filled every
place in every session for the rest of the day, and no new vocabulary appeared after day
one. The reinforcement was worth keeping; representing it as an appointment was not.

## Consequences

Anyone who knows spaced repetition expects sub-day learning steps, because the well-known
tools have them. A ladder whose first interval is a day therefore looks like a missing
feature. It is deliberate, and restoring short intervals as due dates reintroduces the bug
this project was rebuilt to fix.
