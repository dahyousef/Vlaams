# Vlaams

Flemish Dutch taught by spaced repetition to someone who already speaks another
language. The vocabulary below is the one the code, the specs and the tickets all use.

## Language

### What is learned

**Item**:
The smallest thing a learner learns: a word, a phrase, a fixed chunk, or a grammar
pattern.
_Avoid_: card, entry, element, élément

**Example sentence**:
A short sentence carrying one item, so the item can be practised in context rather than
alone.
_Avoid_: drill, sentence, phrase

**Gloss**:
An item's meaning, written in the language the learner reads.
_Avoid_: translation, definition, French, English

**be variant**:
The Flemish form of an item, where Flanders says something other than standard Dutch.
_Avoid_: dialect, regional form, Belgicism

**Reference sheet**:
A page of material meant to be consulted, never drilled.
_Avoid_: cheat sheet, cribsheet

### How far a learner has got

**Rung**:
A position on the ladder of demand, from recognising an item through hearing and writing
it to saying it aloud.
_Avoid_: stage, échelon, level, step

**Tier**:
The highest rung an item will ever be asked to reach. A ceiling, not a position — so an
item has both a rung and a tier, and they are never the same thing.
_Avoid_: palier, cap, maximum level

**Met**:
Said of an item the learner has encountered at least once.
_Avoid_: seen, introduced, discovered, rencontré

**Due**:
The moment an item is next scheduled to be put in front of the learner.
_Avoid_: scheduled, next review, échéance

**Lapse**:
A wrong answer on an item that had already climbed above its first rung.
_Avoid_: miss, failure, mistake, rechute

**Retired**:
Said of an item whose interval has grown long enough that it has left the daily rotation.
_Avoid_: graduated, finished, learned, ancré

**Mastered**:
Not used. Progress is described as a count of items **met** and a count the learner can
**produce**.
_Avoid_: mastered, mastery, maîtrisé

### A sitting, and a day

**Exercise**:
One question put to the learner, built from one item.
_Avoid_: task, drill, question, activity

**Session**:
One sitting of exercises, bounded by a maximum number of items.
_Avoid_: lesson, round, séance

**Day**:
The period the budget is counted over. Distinct from a session, because several sessions
can happen in one day and the two bound different things.

**Budget**:
The ceiling on how many exercises a day will serve, set by the pace.
_Avoid_: cap, quota, limit, plafond

**Pace**:
The daily intensity a learner has chosen.
_Avoid_: level, speed, difficulty, rythme

### The course

**Unit**:
A themed group of items, taught in a fixed order.
_Avoid_: chapter, lesson, module

**Gate**:
The condition a unit must satisfy before the next unit opens.
_Avoid_: threshold, requirement, seuil

**Frontier**:
The furthest unit a learner has opened. Every unit up to it is available, and it never
moves backwards.
_Avoid_: current unit, progress point, position

**Alias**:
A second listing of an item that is already taught elsewhere, sharing the original's
progress rather than keeping its own.
_Avoid_: duplicate, copy, repeat

### Who the learner is

**Display language**:
The language the interface and the glosses appear in. A setting the learner chooses.
_Avoid_: locale, language, UI language

**Native language**:
The language the learner already speaks, which determines what comes free to them. Not
the same as the display language, and not a setting — someone can read English glosses
while French is still what makes a word easy.
_Avoid_: mother tongue, first language, L1

**Cognate**:
An item whose meaning is free to a learner because it resembles the word they already
know for it.
_Avoid_: transparent word, loanword, mot transparent

### Free production

**Open task**:
A prompt asking the learner to compose their own sentence, judged on stated requirements
rather than against one correct answer.
_Avoid_: free exercise, essay, open question

**Need**:
One requirement an open task's answer has to satisfy.
_Avoid_: criterion, rule, check

**Rubric**:
The full set of an open task's needs, taken together.
_Avoid_: marking scheme, grader

**Model answer**:
One answer that satisfies every need, shown after the learner has written theirs. An
example, never the only right answer.
_Avoid_: correct answer, solution, expected answer
